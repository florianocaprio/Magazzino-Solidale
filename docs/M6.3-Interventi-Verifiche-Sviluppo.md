- Handoff storico: richiede nome database `m5c2a_r2_*`; predisposta copia esclusivamente sintetica con quel nome nel PG di attività, mantenuto il guardrail.
- E2E iniziale: prima import dipendenze nel launcher, poi assert su descrizione invece del campo Note realmente esposto; fixture/assert allineati al contenuto verificato, senza modificare UI per il test.
