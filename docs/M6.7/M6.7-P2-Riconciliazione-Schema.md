## 2. Root cause e riconciliazione

Il conteggio dei vincoli non era una misura delle protezioni effettive. Le tabelle create dal bootstrap Drizzle esistono già quando le migration storiche incontrano `CREATE TABLE IF NOT EXISTS`: i CHECK e le FK inline di tali CREATE non vengono aggiunti. Il clone storico, invece, conserva i vincoli nati con quei CREATE. Si aggiungono differenze rappresentative, alias e vincoli ridondanti.
