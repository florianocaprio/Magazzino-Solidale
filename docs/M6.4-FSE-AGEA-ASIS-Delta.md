## Limiti espliciti

Durante sviluppo il browser M3B ha rilevato una regressione della nuova query lista Carichi: `ANY` con array interpolato da Drizzle generava SQL non valido. Corretto con `inArray`/false; aggiunta prova scope multiplo/vuoto e ripetuti con successo API ed E2E M3B. Non attribuita a un difetto della baseline.

Il nuovo raccordo M3B richiede una fonte esterna versionata persistente: il requisito non è soddisfatto dalla riconciliazione interna Registro/Giacenze. La minimizzazione dei nuovi export non bonifica retroattivamente gli storici. Le due decisioni sono dettagliate in `M6.4-Decisioni.md`. La milestone completa non è chiusa.
